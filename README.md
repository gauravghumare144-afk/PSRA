# PRIA Complete — Repeating Alarm Edition

## Main behavior
If Sir enters:
- Goal: `go to rest`
- Time: `4:22 PM`

At 4:22 PM PRIA displays:

**"It's time to go to rest now."**

The alarm starts repeating until:
- **Mark Goal Complete** is pressed, or
- **Dismiss Alarm** is pressed.

Multiple goals can be scheduled for the same time; they are combined into one repeating reminder.

## Daily 6 AM reminder
At 6:00 AM PRIA displays:

**"It's time to set today's goals."**

## Important browser limitation
A GitHub Pages PWA cannot guarantee a loud alarm when the operating system has completely stopped/suspended the browser. The repeating sound works while PRIA is active and notification permission can provide a notification. For stronger background alarm behavior, a native mobile app would be required.
